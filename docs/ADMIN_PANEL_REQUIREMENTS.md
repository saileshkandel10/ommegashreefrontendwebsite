# Admin Panel Requirements

Custom Laravel admin (no Filament).

Modules: dashboard, homepage, company profile, chairperson message, board, departments, products, categories, GMP, milestones, news/blog, notices, downloads, gallery, careers, applications, enquiries, SEO, translations, navigation, media, users, roles/permissions, settings.

Capabilities: CRUD, publish/unpublish, drafts, scheduling, uploads, ordering, bilingual content, SEO fields, slug management, preview.
Roles: Super Admin, Content Manager, Product Manager, HR Manager, Editor.
