# Brand Design System

Colors: #B72E5B (primary), #306B83 (secondary), #F8E9EF (soft pink), #FAF8F9 (bg), #252329 (text), #FFFFFF.

Typography: Inter/Sora, Noto Sans Devanagari for Nepali.
Radius: cards 20px, buttons pill, inputs 12px.
No gradients, no extra hues. Hover via opacity.
Min touch target 44px, contrast 4.5:1, visible focus rings.
Logo 60px header/footer, 40px mobile mark.
