# Functional Requirements

- Public site: home, about, departments, products, quality, disclosure, careers, contact.
- Bilingual EN/NE with language switch.
- Product catalogue with search/filter/pagination.
- Job applications with CV upload (PDF/DOC/DOCX, 5MB).
- Contact/dealer/quote inquiries.
- SEO: titles, meta, canonical, OG, sitemap, JSON-LD.
- Spam protection: Cloudflare Turnstile.
- Optional commerce: Khalti/eSewa or quote-only.
- Email via cPanel SMTP, sync/db queue.
